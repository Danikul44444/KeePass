# 📦 Менеджер паролей (KeePass GUI)

Простое десктопное приложение на Python для локального хранения и управления учетными данными (сайты, заголовки, логины, пароли). Построено на стандартной библиотеке `tkinter` и базе данных SQLite.

---

## 📖 Описание
Приложение предоставляет графический интерфейс для:
- ➕ Добавления новых записей (сайт, название, логин, пароль).
- 📋 Просмотра сохраненных данных в табличном виде.
- 🔒 Базовой защиты паролей при хранении в БД (простое шифрование).
- 👁️ Переключения видимости пароля в поле ввода.
- 🔍 Поиска по записям (UI готов, логика требует доработки).

---

## ⚙️ Принципы работы
Архитектура приложения разделена на 4 модуля по принципу разделения ответственности:

1. **Интерфейс (GUI)** → `module_run_gui.py`  
   Создает главное окно, настраивает сетку виджетов, подключает тему и запускает основной цикл событий `mainloop()`.

2. **Логика представления (View/Controller)** → `module_view_script.py`  
   Содержит вспомогательные функции: кастомные поля ввода с плейсхолдерами, обработчики кнопок, загрузку данных в таблицу и переключение видимости пароля.

3. **Хранение данных (Database)** → `module_database.py`  
   Отвечает за взаимодействие с SQLite: создание схемы, вставку новых записей, выборку всех или последней добавленной записи.

4. **Криптография (Hasher)** → `module_hasher.py`  
   Выполняет простое шифрование/дешифрование паролей перед записью в БД и при отображении в интерфейсе. Используется сдвиг ASCII-кодов символов на фиксированный ключ (`256`).

**Поток данных:**
```
Пользователь вводит данные → module_view_script.py проверяет плейсхолдеры → 
module_hasher.py шифрует пароль → module_database.py сохраняет в SQLite → 
При загрузке: БД → hasher (декод) → Treeview (таблица)
```

---

## 📁 Структура проекта и ответственность файлов

| Файл | Назначение | Ключевые функции |
|------|------------|------------------|
| `module_run_gui.py` | Точка входа, сборка интерфейса | Настройка окна, сетки, темы, размещение панелей, запуск `mainloop()` |
| `module_view_script.py` | Логика UI и обработчики | `Entry()` (фабрика полей с плейсхолдером), `add_information()` (добавление), `toggle()` (видимость пароля), `open_table()` (загрузка таблицы) |
| `module_database.py` | Работа с SQLite | `create_table()`, `add_info()`, `get_end_info()`, `get_all_info()` |
| `module_hasher.py` | Простое шифрование | `hash()` (кодирование), `decode()` (декодирование) |

## 🚀 Как запустить
1. Убедитесь, что установлен **Python 3.7+**.
2. Создайте папку `database` в корневой директории проекта (требуется для сохранения `data.db`).
3. Запустите главный файл:
   ```bash
   python module_run_gui.py
   ```
4. *(Опционально)* Для применения темной темы `forest-dark` поместите файл `forest-dark.tcl` в папку `theme/` относительно корня проекта.

## ⚠️ Важные замечания и ограничения
| Аспект | Статус | Комментарий |
|--------|--------|-------------|
| 🔐 Безопасность шифрования | ⚠️ Базовое | Используется простой сдвиг ASCII-кодов. **Не является криптографически стойким**. Не подходит для хранения реальных конфиденциальных данных. |
| 🔍 Поиск | 🛠️ Не реализован | Кнопка и поле поиска присутствуют в UI, но обработчик нажатия не привязан к функции фильтрации таблицы. |
| 👁️ Переключатель пароля | 🐛 Баг аргументов | В `module_run_gui.py` вызов `command=toggle` не передает аргументы `mode_switch` и `password_entry`, что вызовет `TypeError` при нажатии. Требуется `command=lambda: toggle(mode_switch, password_entry)`. |
| 🗄️ Инициализация БД | ⚠️ Папка `database` | Если директория `./database/` не существует, `sqlite3.connect()` выбросит ошибку при первом запуске. |
| 📜 `pprint` в БД | ⚠️ Отладка | Вызов `pprint(get_all_info())` в `module_database.py` выполняется при каждом импорте модуля. Рекомендуется удалить или завернуть в `if __name__ == "__main__":`. |

💡 *Проект подходит в качестве учебного примера архитектуры десктопного приложения на Python. Для production-использования рекомендуется заменить простой шифратор на `cryptography.fernet` или `bcrypt`, доработать поиск и обработку ошибок БД.*
